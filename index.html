    快捷鍵

    B / E / G鉛筆 / 橡皮擦 / 油漆桶（Shift+點擊 = 全域同色）
    L / R / O直線 / 矩形 / 橢圓（Shift 限制角度或比例）
    M選取；拖曳選取框內可移動；Ctrl/Cmd+C、X、V 複製、剪下、貼上；Delete 清除
    I 或 Alt滴管（Alt 為暫時切換；右鍵取到背景色）
    H / V水平 / 垂直鏡像繪圖
    [ ]縮小 / 放大筆刷
    X交換前景與背景色
    空白鍵 + 拖曳平移畫布（中鍵、雙指也可以）
    滾輪 / 雙指縮放畫布
    + − 0放大 / 縮小 / 符合視窗
    #顯示或隱藏格線
    , .上一格 / 下一格
    Enter播放 / 暫停
    Ctrl/Cmd+Z復原（Shift+Ctrl/Cmd+Z 或 Ctrl+Y 重做）
    Ctrl/Cmd+S / O / E存檔 / 開啟 / 匯出
    Ctrl/Cmd+A選取整張畫布
    Esc取消選取
